# 本轮交付与收尾（2026-10-25）

本轮已结束：保留全量训练一遍的微调权重，可见概率 **p ≥ 0.85** 判为可见；原模型继续保留，阈值为 **0.5**。当前选择用于实验与真实演示合图对照，尚未替换部署 engine。没有追加训练、扩批或连续视频实验。

## 最终结论

完成了编辑器基准规则导出、自动抽样和合成数据生产、MAMMA 数据适配与微调、统一合成验证，以及真实图片点位和双机演示合图对照。

| 项目 | 原模型（0.5） | 本轮模型（0.85） |
| --- | ---: | ---: |
| 合成验证 ERP 点均误差 | 4.3954 px | 2.5242 px |
| 可见召回 | 82.64% | 91.33% |
| 遮挡召回 | 95.73% | 94.76% |
| 40 对真实图片中成功变形的帧 | 37 | 35 |
| 共同成功的 35 帧中用于变形的点对 | 2,474 | 3,665 |

统一验证为 7 场景、814 条观察，点位误差下降约 **42.6%**。阈值 0.85 是查看该验证集后选择，结果属于同集选择后的描述，不是独立测试。训练为 28 场景、3255 observed 中的 3245 条有效观察各一次；10 条全无监督排除。batch=4，共 812 次更新，尾批 1 条，AdamW lr=1e-5，FP32、class_mean。

原模型自身在这 814 条观察上的 0.10–0.95 阈值扫描见[训练报告的原模型阈值扫描](CITY_MERGED_FULL_EPOCH_20261025.md#原模型的阈值扫描)。这是同集描述性分析；当前演示仍使用原模型 0.5、本轮模型 0.85。

用户对真实演示合图的总体判断是：**两组效果相近，本轮模型的主要收获是可用对应点更多。** 共同成功帧中的点对数增加约 48.1%，但人物配对可能不同，不能据此宣称点对精度提高。微调模型仍有 3 帧被网格门槛拒绝、2 帧无配对；更多点尚未转化成明显的合图视觉提升。

真实图片没有人工点位真值，用户判断不是逐帧评分或真实准确率。本轮沿用 riding-data 的演示链：D 人物配对 → cam4 到 cam2 变形准入 → 简化局部位移网格 → E 归属与硬覆盖；**不是 canonical CPW 或公司的最终合图实现**。未验证连续视频稳定性。详细记录见[训练报告](CITY_MERGED_FULL_EPOCH_20261025.md)及[合图报告](REAL_RIDING_STITCH_THRESHOLD085_20261025.md)。
